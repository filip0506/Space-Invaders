# Space Invaders

Space Invaders

An old course project from 2019, built with C++ and SFML. A Space Invaders-style arcade game with a few custom features, power-ups, and a high-score system.
Features

    Classic Space Invaders-inspired gameplay
    High-score system
    Power-ups:
        Damage Up — increases damage
        Rate of Fire — increases firing speed
        HP Recovery — restores health
    A red mothership that drops a random power-up when destroyed

Known Issues & Missing Features

    No defensive shields like in the original Space Invaders.
    Enemies cannot shoot at the player.
    Enemies in the top row may become vertically misaligned with the rest of the formation.

This is an old project, so I may fix the remaining bugs or use it as a starting point for a new version.
